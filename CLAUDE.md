# Claude — правила роботи з Konoha Gaiden Chronicles

Завжди прочитай кореневий `AGENTS.md` і дотримуйся його перед аналізом чи зміною файлів цього репозиторію. Інструкції конкретної підсистеми (зокрема `AI_AGENT_PIPELINE/README.md` та EDIT GATE) також обов'язкові.

1. **Не впевнений — запитай**, а не вигадуй.
2. **50 рядків, а не 200**: віддавай перевагу малим завершеним змінам; більший обсяг обґрунтуй.
3. **Чіпай лише потрібне**, збережи незачеплені файли, ID та авторські рішення.
4. **Спочатку — як перевірити**: визнач тест/валідацію або ручну перевірку до редагування; після вкажи фактичний результат.

Ці правила діють також для чатів Claude, які працюють із вмістом репозиторію.
