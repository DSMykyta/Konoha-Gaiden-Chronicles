# Konoha Gaiden Chronicles

У корені репозиторію зберігаються лише загальні службові файли та каталоги окремих проєктів.

Основні каталоги:
- `Haigakure/` — Країна Чаю та Хайґакуре; актуальні матеріали, джерела, архів і візуальні референси.
- `Kalendar_Konoha/` — календар Конохи та пов’язані матеріали.
- `KAKASHI_GAIDEN_NOVEL/` — романна версія Kakashi Gaiden.
- `kakashi_gaiden_ARCS_FULL_LOG_FIXED/` — архів зіграних арок, хронологія та джерельні логи.
- `Iniichi Team/` — кампанія Юґірі Мікати, матеріали команди Іноїчі та профілі.
- `TEAM9_AGE12_MAXIMUM/` — матеріали Team 9.
- `Kusagakure_Exam/` і `KONOHA_GAIDEN_ARCS_ZIGRANE_POV_V3/` — матеріали ліній Кусаґакуре та Ейзана.
- `Kitcune Kon Gaiden/` — матеріали Kitsune Kon.
- `AI_AGENT_PIPELINE/` — робочий пайплайн агентів.

Докладні індекси та правила лежать усередині відповідних каталогів.
