# Ейзан — іспит у Кусаґакуре

Активна зведена редакція: **V4.4**. П’ять арок від першого етапу до оголошення підвищення Шігуре.

Гра від особи шістнадцятирічного Тачібани Ейзана — досвідченого геніна Кусаґакуре, який утретє складає іспит на чуніна. Він володіє Дотоном і Суйтоном, користується парними кусарігамами. Шігуре спеціалізується на отрутах і сенсориці, Горо — на пастках та вибухових печатках. Іспит індивідуальний; співпраця в лісі є їхнім власним рішенням.
