## Межі, для яких потрібне первинне джерело

**Потрібен первинний канон**, тільки якщо редактор обере додавати прихований зміст замість мінімального вилучення: кому й чому адресовано реакцію Цунаде («Канкуро? Ясуші?»), що саме обговорювали троє очільників за зачиненими дверима, чи мають бути нові домовленості після фіналу. V2 цього не встановлює, аудити не підтверджують. Без такого джерела нових фактів не вводити; для рекомендованих вище мінімальних корекцій ця прогалина не є блокером.

№16 сам не висуває нових редакторських претензій, а дає тематичне прочитання. Його формули про завершену особисту відповідальність та сімейний зв'язок не зобов'язують V3 до морального висновку й перекриті прямими новими рішеннями.
