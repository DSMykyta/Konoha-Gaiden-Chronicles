# «Ті, хто залишився», V3 — матеріали для відновлення

Читати: [SEIGO_TI_KHTO_ZALYSHYVSIA_V3.md](SEIGO_TI_KHTO_ZALYSHYVSIA_V3.md).

У папці є дев’ять завершених розділів, побайтово збережені авторські вкладення, вихідна V2, звірення наданих аудитів, донорські механізми, редакторські рішення, два повних читання, перевірки локальних ремонтів та точні хеші. Це архів матеріалів цієї редакції; повна історія контрольних комітів лишається в репозиторії.

Після збою почати з RESUME.md, STATE.json і PUBLICATION.json. Вихідні вкладення описані у SOURCE_MANIFEST.json; цілісність V3 — у INTEGRITY_CHECK.json. ARCHIVE_MANIFEST.json містить SHA256 і розмір кожного файла всередині архіву. Не перезаписувати CHAPTERS/ старою BASE_V2.md.

Нові авторські вказівки мають пріоритет. Деталі двох невстановлених боїв і закритої пропозиції Мей не вигадувати. Перевірки не є новим циклом усіх 38 аудитів.
