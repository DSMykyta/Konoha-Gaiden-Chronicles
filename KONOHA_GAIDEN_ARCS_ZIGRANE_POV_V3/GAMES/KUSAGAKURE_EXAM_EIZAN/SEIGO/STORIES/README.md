# Літературні тексти Сейґо

[«Ті, хто залишився» — новий повний драфт V1](SEIGO_TI_KHTO_ZALYSHYVSIA_V1.md).

Самостійна політична повість у шести розділах: повернення шинобі з найманства, насильство на дорозі під знаком Куси, цивільні борги й політична ціна платні. Іспит — кульмінаційна подія, а не вся сюжетна рамка.

Статус: завершена літературна версія для авторського читання. Нові люди й події цієї версії залишаються творчими рішеннями драфту; до канонічної хронології їх не внесено.
