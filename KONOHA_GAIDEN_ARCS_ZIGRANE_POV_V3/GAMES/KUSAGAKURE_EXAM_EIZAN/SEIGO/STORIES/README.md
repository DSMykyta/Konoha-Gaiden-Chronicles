# Літературні тексти Сейґо

[«Ті, хто залишився» — поточна редакція V2](SEIGO_TI_KHTO_ZALYSHYVSIA_V2.md).

Самостійна політична повість у дев’яти розділах: насильство на дорозі під знаком Куси, повернення шинобі з найманства, цивільні борги, родинний догляд і політична ціна платні. Іспит, міське свято й гості збільшують тиск на тимчасового очільника. У V2 друга половина розгорнута в сцени; додані Ясуші за чаєм, сварка із сестрою, субота з Мей і видимі події фіналу.

Статус: завершена літературна редакція для авторського читання. Нові люди й приватні події повісті не внесені автоматично до канонічної хронології.

Опори та межі: [SOURCE_AND_DESIGN.md](../WORK/TI_KHTO_ZALYSHYVSIA_V2/SOURCE_AND_DESIGN.md). Реальні редакторські проходи й виправлення: [EDITORIAL_CHECK.md](../WORK/TI_KHTO_ZALYSHYVSIA_V2/EDITORIAL_CHECK.md).
