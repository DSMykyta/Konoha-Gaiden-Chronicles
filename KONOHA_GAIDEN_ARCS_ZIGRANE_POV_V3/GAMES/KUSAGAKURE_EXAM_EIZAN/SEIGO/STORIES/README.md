# Літературні тексти Сейґо

[«Ті, хто залишився» — поточна редакція V3](SEIGO_TI_KHTO_ZALYSHYVSIA_V3.md).

**Чинне авторське уточнення:** на білих масках двох охоронців Ясуші — три риски емблеми **Хай**, не Куси. Чайна розмова та спостереження з ложі за Нагі й наступним боєм уточнені в основному файлі V3 без встановлення нових переможців або технік. Історичні хеші та тексти звітів у `WORK` засвідчують попередні знімки й не замінюють останній текст у `STORIES`.

Оновлено після дрібних авторських правок і перенесення чайної сцени. Розмова з Ясуші відбувається в четвер після початку допомоги Хайґакуре, у вже знайомому малому залі. [Перевірка цієї правки](../WORK/TI_KHTO_ZALYSHYVSIA_V3_TEA_REVISION/REVIEW.md).

Політична повість у дев’яти розділах про тимчасового очільника Куси, дорожній напад під знаком селища, повернення шинобі, борги й родинний тягар. Іспит, міське свято та гості збільшують тиск; публічний успіх не скасовує політичного розгляду й нестачі людей.

V3 перероблена за авторськими нотатками, наданими аудитами, оглядами й донорськими механізмами. Умови Кендзо показані в діалозі; допомога Ясуші безоплатна без розкриття задуму; суботня вечеря й контакт із сестрою не дають автоматичного примирення. Прибрані зайві медичні кризи другого етапу та реміснича розв’язка Міцу.

Статус: завершена редакція для авторського читання. Нові приватні події повісті не перенесені автоматично до загальної канонічної хронології. Два фінальні бої без установлених пар і результатів лишаються подіями тла ложі; нова хореографія для них не вигадана.
