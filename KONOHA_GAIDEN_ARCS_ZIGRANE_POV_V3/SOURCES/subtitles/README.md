# Subtitle sources

Робоча папка для субтитрів, які використовуються як допоміжне джерело під час перевірки хронології.

## Серіали

- `naruto-part-i/` — Naruto (2002), епізоди 001–220.
- `naruto-shippuden/` — Naruto Shippuden (2007), епізоди 001–500.

## Рекомендований формат файлів

```text
naruto-part-i/001.srt
naruto-part-i/002.srt
...
naruto-part-i/220.srt

naruto-shippuden/001.srt
naruto-shippuden/002.srt
...
naruto-shippuden/500.srt
```

## Використання

Субтитри — додаткове джерело для відновлення порядку реплік і коротких дій, яких може не бути в Narutopedia Synopsis. Вони не замінюють перевірку самого епізоду та Narutopedia.

Повні субтитри не комітяться сюди автоматично зі сторонніх баз. Додавайте лише файли, які ви маєте право використовувати.
