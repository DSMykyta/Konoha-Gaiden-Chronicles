# Географічний реєстр хронології — ревізія

## Правило

Географічна відстань на схемі — **якісний рівень близькості**, а не вигадані кілометри чи координати. Структура: країна → населений пункт → будівля/місцевість → кімната. Географія впливає тільки на вертикальне розходження ліній; координата часу X залишається недоторканною.

Основне джерело локацій: `data/entities.yaml`; обережні доповнення: `data/geography.yaml`. Батьківський зв'язок з джерела не можна суперечливо перекривати. Дані канону, філерів і авторського розширення не змішуються під виглядом одного доказу.

## Результат інвентаризації

У вихідному довіднику **177 локацій**, із них **52 без `parent_id`**. Частина з цих 52 — повноцінні країни, для яких батько не потрібен; інші мають визначену територію або залишаються невідомими.

Тепер зареєстровано тип `country` для вже наявних країни Вогню, Хвиль, Снігу, Чаю, Рисових Полів, Річок, Птахів, Моря, Ведмедів, Іклів, Кігтів, Зелені, Меду, Місяця і Гірських Потоків. Для Сунаґакуре та Такіґакуре додані країна Вітру і країна Водоспадів. Відмічено вкладеність Конохи, Сунаґакуре, Академії, Ічіраку, резиденції Хокаґе, Лісу Смерті, Танзаку, місць Країни Хвиль та кількох підтверджених околиць Конохи.

Контрольні приклади:

| Місця | Зв'язок |
|---|---|
| Клас Академії та учительська | Та сама будівля |
| Ічіраку та резиденція Хокаґе | Те саме селище (Коноха) |
| Коноха та Танзаку | Одна країна (Країна Вогню) |
| Коноха та Країна Снігу | Різні країни |
| Коноха та Сунаґакуре | Різні країни |
| Сцена без локації та Коноха | Невідомо — жодного автоматичного зближення чи відштовхування |

## Записи без підтвердженої країни

Потребують окремої перевірки за сценами та джерелами, перш ніж додавати `parent`:

- `loc-team9-ravine`, `loc-team9-catacombs` — тренувальні ділянки команди 9
- `loc-akagahara`, `loc-nekomata-domain`, `loc-honegami-field` — окремі локації джерел
- `loc-nagi-island`, `loc-modoroki-shrine`, `loc-valley-of-evil` — країна не закріплена в довіднику
- `loc-gelel-coast`, `loc-gelel-ruins` — місцевості історії Ґелеля
- `loc-hot-springs-town`, `loc-motoyoshi-village`, `loc-fuku-castle`, `loc-mugen-castle` — необхідна перевірка походження та географії
- `loc-yakumo-villa`, `loc-oto-base2`, `loc-oto-base18` — місцевості без надійного батьківського регіону
- `loc-shukuba-contact-room` — місто Шукуба відоме за назвою, але країна ще не підтверджена
- `loc-valley-end` і `loc-valley-of-end` — два ідентифікатори одного місця, об'єднані логічно, без створення дубля

Окремий випадок — **місце або країна навмисно не визначені**:

- `loc-inn` — неназваний заїжджий двір
- `loc-iwa-mercenary-mines` — прикордонна місцевість, без вигаданого боку кордону
- `loc-road-fire-waves`, `loc-moon-escort-route` — маршрути між місцями
- `loc-gelel-caravan`, `loc-haido-moving-fortress` — рухомі об'єкти
- `loc-time-slip-toad-stomach` — внутрішній простір, не фізична географічна точка

**Не можна** автоматично присвоювати всім невідомим місцям Коноху або країну Вогню. Показник «невідоме» у бічній панелі стосується *видимих за шарами сцен*, а не всіх 177 місць.

## Перевірка переміщень

Окремий механізм позначає **для перевірки**, а не як помилку, випадки, коли той самий фізично присутній персонаж має події в різних підтверджених країнах в одну календарну добу. Потрібно вручну перевіряти послідовність, часові позначки, клони, телепортацію, спеціальні техніки, відгалуження сюжетів та філери. Невідоме місце не створює такого попередження.

Список невідомих місць, які використовуються в поточній конфігурації шарів, і підозрілі записи відображаються в **Період → Географія та невідомі місця** на сайті. Це реєстр для редакторської перевірки, а не автоматична корекція сюжетних фактів.
