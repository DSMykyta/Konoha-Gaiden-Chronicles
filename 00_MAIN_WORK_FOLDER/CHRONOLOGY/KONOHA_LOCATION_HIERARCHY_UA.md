# Підпорядкування локацій Конохи

Станом на 19.10.2026. **Країна → селище → територія / будівля → кімната / точка сцени**. Це фізична вкладеність, а не твердження про близькість усіх місць одного типу. Усі старі ID сцен збережено.

Джерела: `data/entities.yaml`, `data/geography.yaml`, транскрипти ігор у `00_MAIN_WORK_FOLDER/GAMES/`, згадані у `SOURCES/narutopedia/` описи. Класифікація нових вузлів: `provenance: project_transcript` — авторські сцени, `canon` — канонічні локації, `structural_group` — узагальнення для підпорядкування, а не новий сюжетний факт.

## Правила та відкриті питання

- `loc-konoha-bank` і `loc-yamano-bank` збережено як різні вузли; ідентичність не встановлена.
- `loc-konoha-hot-springs`, `loc-konoha-public-bath`, `loc-time-slip-bathhouse` не злиті без доказу.
- `loc-chunin-exam-room` і `loc-chunin-written-exam` можуть бути назвами однієї аудиторії; до звірки сцен залишено два ID.
- `loc-team9-ravine`, `loc-team9-catacombs`, `loc-inn` і місця з невідомими кордонами залишені без вигаданих батьків.
- `geo-konoha-academy` — уже наявний канонічний вузол будівлі; дубль Академії не створено.
- Уточнено 23 батьківських зв'язків, додано 65 нових вузлів, з них 4 — вузли-групування. Часові якорі, сюжети, зв'язки фізичної присутності не змінювалися.
