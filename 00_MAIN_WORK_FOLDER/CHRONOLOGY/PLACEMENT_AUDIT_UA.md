# Звіт перевірки хронології — початковий стан

**Статус: перевірка всього репозиторію ще не виконана.** Створений інструмент `placement_solver.py` читає вихідні YAML і генерує цей файл після реального запуску. Тут немає вигаданих результатів аудиту.

## Що реалізовано

- Зчитування активних сцен, фізичних учасників, дат із `time-anchors.yaml` і реконструкцій із `mission-windows.yaml`.
- Звірка прийнятих зв'язків `before` та мінімальних підтверджених інтервалів між сценами.
- Виявлення перетинів з установленими періодами місій, дороги та відновлення.
- Окреме позначення можливого пересування між країнами в один день як **підозри**, а не доведеного порушення.
- Дозвіл паралельної роботи незалежних команд.
- Підбір кандидатних дат лише там, де доведені обидві межі; опціональна перевірка сумісності через Google OR-Tools.

## Виконані та невиконані перевірки

- Десять сценарних локальних тестів початкової реалізації пройшли на синтетичних YAML-даних.
- Повний аудит актуального набору сцен із GitHub **не запускався**: повна копія репозиторію відсутня у доступному середовищі запуску.
- Оптимізатор Google OR-Tools тут не встановлено; доступний без нього режим перевіряє інтервали, але не дає гарантії глобальної оптимальності.

## Наступний запуск

Команда в `PLACEMENT_SOLVER_README_UA.md` замінить цей початковий запис конкретним звітом: кількість сцен, підтверджені суперечності, підозри, вільні допустимі інтервали й зафіксовані відсутні дані. Поки цього не сталося, не заявляти, що вся хронологія перевірена.

Сюжетні файли, початкові дати та налаштування SITE не змінені.
