# REPORTS

Сюди worker-чати записують результати відповідно до правил у `../README.md`.

Не клади сюди master-промпти або вихідні літературні файли.

Стандартний шлях:

```text
REPORTS/<target-key>/<source-blob-sha8>/<EDITING|WRITING>/<task-id>.md
```

Blob SHA береться з цільового файла. Тому всі незалежні агенти, які аналізують ту саму редакцію текста, потрапляють в одну папку навіть якщо між їхніми запуском з'являються нові коміти зі звітами.
