# Прототип часових капсул SITE — 19.10.2026

Первісна гілка: `feature/semantic-capsule-layout`. Реалізацію перенесено до `main` під час консолідації гілок 20–21.10.2026. Календарні дати та шарові фільтри збережено. Деплой не виконувався.

## Концепція

- **Арка** — самостійна кольорова капсула, яку не можна зливати з іншою аркою.
- **Епізод** — кольорова капсула, що успадковує колір арки.
- **Сцена** — капсула з того самого колірного сімейства, навіть якщо містить один момент.
- **Момент** — крапка в кольорі арки.
- **Лінії персонажів** лишаються окремими кривими фізичної присутності; не визначають ID сюжету й не створюють об'єднану сцену.
- **Час X** спільний для всіх масштабів; фокус, локації й анімація не змінюють календарних координат.
- При масштабуванні дочірні капсули пружно стискаються до батьківських, батьківська капсула розкривається. Внутрішньоденні відрізки мають похідні порядкові X без вигаданих точних годин.
- Сцени одного епізоду можуть з'єднуватися короткими відгалуженнями. Сцени різних епізодів не зливаються через спільного персонажа. Тривалі пропуски часу залишаються пропусками.

## Реалізоване

- `SITE/public/interval-capsules.js`: пласкі контури, кольорова спадковість за `episode.arc_id`, календарні ширини, перетворення під час зуму, зв'язування сцен лише в одному епізоді. При кількох фізичних місцях однієї сцени на масштабі моментів відображаються її окремі просторові сегменти.
- `SITE/public/app.js`: капсули малюються під лініями персонажів; моменти — окремими пласкими крапками; хіт-області сцен/епізодів/арок прямокутні; компонування арок не допускає взаємного накладання їхніх капсул на календарному огляді. Старі рідкі краплі не відображаються в цьому прототипі.
- `SITE/public/timeline-core.js`: підсилено прив'язку до спільного епізоду та місця порівняно з тяжінням персонажів; вихідні моменти й дати не переписано.
- `SITE/public/story-clouds.js`, `style.css`, `index.html`: спадковість кольору, пласкі стилі й завантаження нового модуля. Службові групи збережено для старих назв/панелей.
- `SITE/tests/interval-capsules.test.mjs`, адаптація DOM-тесту `interface.cjs` і тестів географії/кольорових форм; тестовий workflow налаштовано для гілки та скасування дубльованих запусків.

## Географія Академії

Джерело вкладеності — `data/entities.yaml` + `data/geography.yaml` через `GeographyAtlas`; фізична близькість впливає на Y і зв'язність, а не на час.

- Додано `loc-academy-corridor`, `loc-academy-empty-room`, `loc-academy-restroom` як вкладені місця `geo-konoha-academy`.
- `sc-y0-0122-sakura-searches-sasuke` — відома сцена коридору; `sc-y0-0122-team10-lunch` — відома сцена коридору (прямі згадки у прозі).
- Шести моментам `sc-y0-0122-naruto-impersonates-sasuke` надано локальні місця: порожній клас або коридор. Сцена як ціле **не має одного точного місця** і залишається `location_id: null`; це не помилка, яку коректно усунути однією назвою.
- `SITE/scripts/build.mjs` бере явне місце моменту перед загальним місцем сцени.

## Невирішене / обмеження

- **Не всі `null` у репозиторії заповнено.** Чернеткова багатолокаційна ретроспектива Какаші й інші непідтверджені місця не повинні отримувати вигадані координати чи приміщення. Для них потрібен поділ сцени або звірка першоджерел.
- Часовий інтервал в межах дня визначається впорядкуванням моментів, якщо джерело не дає тривалості. Довжина є відображенням реконструкції, не хронометражем аніме.
- Пружний морф капсул — перша проста версія; поки немає остаточного декору/матеріалу.
- Повний браузерний візуальний огляд і Playwright-скріншоти виконувати тільки після доступної тестової збірки. Не заявляти про проходження CI, доки GitHub Actions не поверне `success`.

## Не змінено

Аніме/ігрові джерела, ID подій, календарні якорі, фізичну присутність, порядок `before`, тексти сцен (окрім уточнених полів місць), Vercel.
