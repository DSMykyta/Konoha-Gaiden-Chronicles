# Прототип інтервальних капсул — експериментальна гілка

Гілка: `feature/interval-capsule-timeline`. Не зливати в `main` без браузерного огляду. Ніякого автоматичного деплою Vercel.

## Принцип
- **Арка**, **епізод**, **сцена** — окремі кольорові прямокутні капсули; кожен рівень успадковує один стабільний колір саме своєї арки.
- **Момент** — кольорова крапка всередині сцени; сцена з одним моментом залишається сценою-капсулою.
- Структура `moment → scene → episode → arc` береться з наявних YAML і обчислених ID, без ручного розкладання чи зміни сюжетної належності.
- Капсули сцени на денному масштабі містять моментні вузли; на віддаленні форми/ширини епізодів та арок успадковуються від дочірніх інтервалів. Різні арки **не зливаються**.
- Лінії персонажів лишаються: моменти однієї сцени розташовуються на горизонтальному каналі, вигини лишаються між сценами.
- Два сусідні сегменти можуть отримати перемичку лише в межах **того самого епізоду**, за близькості на екрані й підтвердженої однакової локації або прийнятого прямого `before`. Різні епізоди не утворюють суцільного контуру навіть у тій самій будівлі.
- Довжина визначається координатами світового часу (`spanStart`/`spanEnd`), не кількістю подій. Для сцен, де є лише одна опора часу, застосовується мінімальна клікабельна ширина, позначена пунктиром: **це не реальна хвилинна тривалість**. На всіх рівнях календар залишається загальним.

## Файли
- `SITE/public/timeline-capsules.js` — палітра, геометрія капсул, відгалуження, умови з’єднання.
- `SITE/public/capsule-timeline.css` — навмисно плаский стиль; майбутня графіка окремим етапом.
- `SITE/public/app.js`, `timeline-core.js`, `index.html` — активація рендера, неперервний зум, горизонталі сцен, семантичні вузли.
- `SITE/tests/capsules.test.mjs` — інваріанти кольору, ширини, singleton-сцен та з'єднань.
- `SITE/scripts/audit-scene-locations.mjs` — аудиторський список пропущених місць без автозаміни.
- `.github/workflows/capsule-prototype.yml` — незалежний CI тільки для цієї гілки.

## Обмеження й наступний аудит
- Автоматичні інтервали всередині одного дня є редакційною розкладкою відносних зв'язків, **не документальною тривалістю в хвилинах**.
- Це перший геометричний прототип, а не фінальний пружний motion-design. Проміжні масштаби використовують чинну плавну інтерполяцію. Потрібен браузерний перегляд щільних сцен і масштабів на мобільному.
- Станом на першу збірку цієї гілки лишилося **96 сцен без відомої локації** у всій базі. Повний список з описами можна отримати `node SITE/scripts/audit-scene-locations.mjs`; за відсутності переконливого джерела не приписувати вигадане місце чи країну.
- `00_MAIN_WORK_FOLDER/CHRONOLOGY/validate_timeline.py` проходив у першому GitHub Actions запуску. `validate_shippuden.py` та деякі старі unit-тести фіксують відсутні шляхи субтитрів `KONOHA_GAIDEN_ARCS_ZIGRANE_POV_V3/SOURCES/`, що не були створені чи видалені цим прототипом. Звіти CI мають зберігати ці відмови видимими, а не приховувати їх.
