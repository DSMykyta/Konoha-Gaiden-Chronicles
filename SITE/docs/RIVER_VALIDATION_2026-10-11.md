# Ревізія геометрії річкових ліній — 11.10.2026

## Підтверджено
- В актуальному `SITE/public/timeline-core.js` реалізовано широкий вертикальний розподіл, безперервні дотичні й стабілізацію команд при зміні близьких локацій.
- Для контрольних даних Команд 7 і 9 використано реальні YAML-сцени: тест дзвіночків, спостереження з Поля 8, Поле 9, яр, катакомби.
- В окремому прямому запуску алгоритму виконано 9 контрольних сценаріїв, включно з реальними YAML-даними (без запуску Node.js test runner). Усі пройшли; це не рівнозначно повному `npm test`.

## Знайдена проблема і виправлення
Раніше команда могла послідовно проходити «країна А → невстановлена локація → країна Б». Звичайний union-find поєднував А з невідомою точкою, потім невідому точку з Б, хоча пряме об'єднання А і Б блокувалося. Це стискало підтверджені різні країни в одну смугу.

Тепер при з'єднанні двох компонентів алгоритм порівнює всі географічні пари між ними й відмовляється об'єднувати компоненти, якщо хоч одна пара має `grade === 4`. Невідома географія залишається невідомою; послідовні підтверджено близькі місця все ще згладжуються.

Додано регресійний тест для транзитивного випадку, а також тест синхронізації версій `timeline-core.js` / `app.js`. Для цих двох файлів оновлено cache-busting на `20261011-spacious-rivers-r2`.

## Ще не перевірено
- Повний набір `npm run check && npm test` у Node.js.
- Рендеринг у реальному Chromium, особливо наскрізна перевірка wheel / drag / pinch / zoom та візуальний стан кривих на різних масштабах.
- Деплой навмисно не запускався.
